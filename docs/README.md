# docs

Assets referenced by the project README.

- `report-screenshot.png` — a screenshot of a generated `karmascout_results.html`,
  showing the ranked cards, score badges, and the two drafted comments per card.
  Generate it with `uv run karmascout --dry-run --output docs/sample.html`, open the
  page, and capture it. The dry run uses fixture threads, so no real thread text or
  personal data ends up in a public image.
